## 双年展黄 · Biennale Yellow

### 设计理念
暖羊皮纸底（#E9E5DB）上泼洒太阳能黄（#F1EE2E），靛蓝墨（#1B2566）书写一切。灵感来自双年展海报的印刷传统——纸张的温暖、墨水的深度、以及一抹不可忽视的黄色。零圆角、零阴影是刻意的——这是一个完全平面的世界，深度通过黄色光晕的透叠来制造。

### 颜色语义
| Token | 色值 | 语义 |
|-------|------|------|
| `--paper` | #E9E5DB | 暖羊皮纸底 — 所有幻灯片的默认背景 |
| `--sun` | #F1EE2E | 太阳能黄 — 唯一强调色，出现于块面、光晕、左侧面板 |
| `--ink` | #1B2566 | 靛蓝墨 — 所有文字、边框、分割线 |
| `--ember` | #E26B4A | 余烬橙 — 暖色点缀，光晕边缘的微量热感 |
| `--haze` | #F0DA7C | 薄雾金 — 黄色→羊皮纸的渐变过渡色 |

### 字体
- **标题**: Noto Serif SC / Songti SC → 文学感衬线，-0.012em 负字距收紧大字
- **正文**: PingFang SC / Microsoft YaHei → 系统无衬线，中英统一
- **等宽**: Cascadia Code / Consolas → 数字、标签、坐标

### 排版规则
- 封面标题 120px–240px 响应式缩放，`letter-spacing: -0.018em`
- 正文 14px–16px，行高 1.5
- 大写标签 11px–13px，`letter-spacing: 0.18em`

### 动效
- 幻灯切换: `ease 0.28s` 软交叉淡入淡出
- 零圆角、零阴影——深度只通过 radial-gradient 光晕制造
