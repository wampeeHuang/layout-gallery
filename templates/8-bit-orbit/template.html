Design Principles

The pixel philosophy behind the 8-Bit Orbit system.

01 / Pixel Precision
4px base unit. steps(4) animation timing. Everything snaps to the pixel grid — no sub-pixel blur.
02 / CRT Nostalgia
Scanline overlay across every slide. Phosphor-like neon glow on dark void. Win95 chrome is real chrome.
03 / Neon Triad
Cyan #5EDCF4, Pink #F0A6CA, Yellow #F4D03F. Three neons on deep navy/void — no fourth accent.
04 / Tektur + Chakra Petch
Tektur geometric display with pixel DNA. Chakra Petch sci-fi body. Space Mono for terminal moments.
05 / Binary Depth
Raised/sunken 3D bevels only. No gradients, no blur, no transparency layers. Depth from light source illusion.
06 / Win95 Honesty
Real titlebars, real buttons, real scrollbars. Not imitation — the actual Windows 95 widget language.
