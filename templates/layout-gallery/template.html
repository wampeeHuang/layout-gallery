Design Principles

六大设计原则

01
Sage Green Authority
#3D6B4A 鼠尾草绿作为唯一品牌色。克制配色让内容成为焦点，色彩只做引导不做装饰。
02
Serif + Sans Dual Font
Noto Serif SC 承载标题与品牌温度，Noto Sans SC 负责正文与界面。衬线/非衬线各司其职。
03
Token-Driven Everything
每套模板的 tokens.json 是唯一真相源。颜色、字体、间距、圆角全部 token 驱动，换 token 即换主题。
04
Editorial White Space
最大宽度 1732px，宽松内边距。留白不是浪费，是阅读节奏的呼吸标记。
05
Six CSS Textures
纯 CSS 纹理系统 — 网格纸、横线本、点阵、噪点、渐变噪点、对角线。零图片依赖。
06
Growth Pipeline
POST /api/grow — 输入网页 URL，AI 提取设计 token，生成完整模板。从网页到模板，一源两端。
