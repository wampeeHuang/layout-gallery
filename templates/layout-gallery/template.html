02 · 证据

标签后面必须有可重建的证据。

页面不硬编码“全绿”结论。机器结果写入 generated/layout-gallery/quality-report.json；这里演示用户需要看到的证据类型与失败边界。

Contract四文件闭合

manifest、intent、tokens、reference 均可独立定位问题。

Runtime资源与控制台

404、console error 与未定义变量任一出现即阻断 Standard。

Responsive三视口证明

390、768、1440 的 scrollWidth 必须等于 clientWidth。

Human review精选另行签署

Standard 不自动升级；Curated 还需要复现与人工审美签名。

03 · Agent 交接

让 Agent 按影响顺序读取，而不是猜。

先知道“是什么”，再理解“为什么”，随后读取可修改控制面，最后参考可执行正例。

  1. template.json
    身份、来源、许可、状态与能力
  2. design.md
    意图、禁用场景、Anatomy 与 Usage patterns
  3. tokens.json
    颜色、字体、间距、动效控制面
  4. template.html
    canonical executable reference
04 · 内容压力

超长标题与多语言元数据也不能挤破网格边界

  • LONG SLUGlayout-gallery-for-institutional-collection-and-agent-reproduction-validation
  • 中英混排策展式结构 Curatorial Structure / 证据优先 Evidence First / 可重复 Reproducible
  • 空值策略缺少来源、许可或质量签署时，隐藏公开入口并返回可操作的缺失项，而不是填充假文案。
  • 极端内容一段足够长的正文用于验证换行、列宽和阅读节奏。它不承担新的产品承诺，只证明页面在信息密度升高时仍然保持鼠尾草绿、衬线标题、细线网格与大留白构成的品牌语法。
