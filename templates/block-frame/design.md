## 概述

BlockFrame 是**极繁新粗野主义幻灯片系统**，建立在五条结构铁律之上：
1. 每个区域有 4px 纯黑边框
2. 每个抬升元素有 8px 硬偏移阴影（零模糊，纯黑）
3. 所有角为直角（唯一例外：统计卡上的 12px 圆形装饰点）
4. 所有强调色为饱和粉彩（粉、蓝、绿、黄、奶油五色）
5. 每个布局允许略微歪斜——倾斜装饰、旋转卡片、错位徽章

系统的乐趣来自这些规则的刻意碰撞——边框叠边框、阴影对阴影、倾斜装饰刺破网格。

## 颜色

### 五色粉彩 + 黑白体系

| 颜色 | 色值 | 角色 |
|------|------|------|

| 粉 | `#FE90E8` | 糖果品红。全幅地面、标签填充、图标方块、星爆填充、图表系列。最饱和的粉彩。 |
| 蓝 | `#C0F7FE` | 冰蓝色。全幅地面（"简介"和"统计"氛围）、标签填充、图表系列。 |
| 绿 | `#99E885` | 春绿色。全幅地面、标签填充、对角条纹图案、图表系列。 |
| 黄 | `#F7CB46` | CTA 颜色。默认按钮填充、合页阴影色、列表编号方块、装饰缺口。最亮最抢眼的粉彩。 |
| 奶油 | `#FFDC8B` | 暖黄奶油。比黄软、比米白饱和。全幅地面、标签填充。 |

### 默认规则

- **默认表面背景**：内容密集型用米白；需更强地面的幻灯片在各粉彩间轮换。
- **默认标题色**：浅色/粉彩地面用黑色；黑色合页地面用白色。
- **默认正文字色**：浅色地面用黑色；深色地面用白色或奶油色。
- **默认边框色**：永远是黑色。唯一例外是反色合页框上的 4px 白色边框。
- **默认卡片填充**：白色。多卡片行中每张卡需独立色标识时才用粉彩填充。
- **默认按钮**：黄色。其他粉彩也可以，但黄色是主要的"点这里"信号。
- **默认标签药丸底色**：白色；粉彩变体（粉/蓝/绿/黄/奶油）标识区域类型。

粉彩在语义角色上可互换——绿色不代表"成功"，红色根本不在色板中。按视觉并列搭配：粉+蓝+绿是最常见三件套；奶油+黄是暖色对；蓝+粉是冷暖对比。

## 排版

### 字体栈

两套字体：

**Inter**（400-900 字重）— 展示、正文、标题、统计数字。900 用于 Hero/合页标题和引文，800 用于主标题，700 用于区域标题和卡片标题，500 用于正文。展示字重永远大写+负字距；正文字重永远句首大写+默认字距。

**Space Grotesk**（400-700 字重）— 标签和 chrome 字体。600 用于标签药丸（13px, 0.08em 字距, 大写），500 用于等宽元数据。虽然技术上讲不是等宽字体，但几何感 + 宽字距处理使它读起来像系统的"代码"声音。

不引入第三种字体。Inter + Space Grotesk 就是全部排版色板。

| 用途 | 规格 | 字重 |
|------|------|------|
| Hero/封面标题 | clamp(48px, 6vw, 96px) | Inter 900 大写 |
| 主区域标题 | clamp(32px, 4vw, 64px) | Inter 800 大写 |
| 区域/图表标题 | clamp(24px, 2.5vw, 40px) | Inter 700 |
| 合页标题 | clamp(40px, 5vw, 80px) | Inter 900 大写 |
| 引文 | clamp(28px, 3.5vw, 52px) | Inter 900 大写 |

| 标签药丸 | 13px | Space Grotesk 600 大写 |
| 幻灯片计数器 | 14px | Space Grotesk 700 大写 |

### 签名处理（强制）

- **每个 Inter 展示元素（heading-xl/lg/quote/close-title）必须大写。** 句首大写的 800+ 字重 Inter 在本系统中不存在。
- **每个展示元素使用负字距**（-0.01 到 -0.03em）。
- **每个标签药丸同时携带 3px 边框 + 4px 阴影 + 大写 Space Grotesk。**
- **每个卡片标题大写的 Inter 700。**
- **每个 Space Grotesk chrome 元素大写 + 0.05-0.1em 字距。**
- **每个统计数字 Inter 900 + 行高 1。** 统计数字是展示时刻，不是数据 chrome。
- **时间线步骤中的步骤编号 48px 900 透明度 0.6。** 全不透明的步骤号会盖过标题。

## 布局

### 画布系统

每张幻灯片 100vw × 100vh。幻灯片绝对定位，通过 `.active` 类的 `display: none/flex` 切换。默认幻灯片内边距 60px。含底部固定网格（时间线、团队网格、含统计列的图表）的幻灯片额外增加 110px 底部内边距以避让固定导航 chrome。

### 持久化 Chrome

每张幻灯片出现三个元素：
- **幻灯片计数器**（左下角）— 3px 黑色边框、白色填充、4px 阴影、Space Grotesk 14px 700 大写，NN / NN 格式
- **导航控件**（右下角）— 两个 48px 方形导航按钮，3px 边框、白色填充、4px 阴影

这些不在 `.slides-container` 内，浮动在底部边缘上方。

### 卡片叠卡片

系统的主要布局模式是**卡片在地面上在地面上**。典型幻灯片：彩色地面 → 白色卡片（4px 黑边框 + 8px 阴影）→ 内含更小的卡片或图标方块。每层嵌套携带自己的边框宽度：外层 4px，内层 chrome 3px。这种嵌套边框结构造就了系统密集、厚实的质感。

## 深度与抬升

### 硬偏移阴影栈

- **`{shadows.default}`** = `8px 8px 0px #000` — 主卡片阴影。Hero 框、特性卡片、引文框、图表框。
- **`{shadows.small}`** = `4px 4px 0px #000` — 次级 chrome 阴影。简介卡片、统计卡、团队卡、时间线步骤、标签药丸、按钮。
- **`{shadows.hover}`** = `6px 6px 0px #000` — 按钮和导航的悬停态。配合 -2/-2 平移，模拟"从页面掀起"。

所有阴影都是纯黑、零模糊、右下偏移。彩色阴影仅出现在暗色合页面：12px 黄色偏移阴影（系统中最响亮的深度声明）和 6px 白色阴影（暗地上的按钮）。

### 倾斜作为深度

系统的趣味性深度签名是**倾斜**。统计卡交替 -2deg / +2deg 旋转。装饰粉矩形倾斜达 ±12deg。Hero 框上的黄色按钮标签倾斜 -3deg。这些倾斜故意打破网格对齐，在不使用透视或阴影的情况下创造感知的立体感。

## 形状与装饰

### 圆角纪律

- **0px** 用于一切结构元素——卡片、标签药丸、按钮、图标方块、列表编号、头像。直角不可谈判。
- **50%（圆形）**仅用于 stat-deco-dot（12×12 圆形强调点，钉在统计卡右上角）。系统中唯一的圆形。

### 边框权重阶梯

- **4px** — 主卡片（Hero 框、特性卡、引文框、图表框）
- **3px** — 次级 chrome（标签药丸、按钮、简介卡、图标方块、列表编号、头像、角括号、导航按钮、幻灯片计数器）
- **2px** — 原子 chrome（图例色板、stat-deco-dot）

无 1px 边框，无 5px+ 边框。阶梯固定。

### 装饰元素类型

- **标签药丸** — 方角边框药丸（3px 黑边框 + 4px 阴影），粉彩或白色填充，Space Grotesk 13px 600 大写 0.08em。通用区域眉毛。
- **角括号** — 卡片四角的 L 形 3px 黑边片段，创建框中框装饰母题。
- **星爆** — CSS clip-path 裁剪的 10 角星形，3px 边框，粉彩填充。钉在合页框和特性卡角落的装饰注意力抓取器。
- **条纹块** — 对角 4px-on/8px-off 黑色+粉彩条纹图案，3px 黑边框。
- **点网格** — 1.2px 径向渐变点阵，24×24 间距。用于幻灯片角落的微弱装饰覆盖。
- **特性装饰缺口** — 48×48 黄色方块，3px 黑边框，绝对定位从特性卡上边缘突出，打破卡片顶边。
- **图标方块** — 64×64 粉彩方块，3px 黑边框，单个大写字母 Inter 700/28px。
- **统计装饰点** — 12×12 圆形，2px 黑边框，粉彩填充，钉在统计卡右上角。系统唯一圆形。
- **列表编号** — 36×36 黄色方块，3px 黑边框，Space Grotesk 14px 700 数字。
- **头像方块** — 72×72 粉彩方块，3px 黑边框，两个大写首字母 Inter 900/28px。填充在粉彩间轮换。
- **步骤连接器** — 28×4 水平黑条，钉在时间线步骤卡片右边缘中高处。连接相邻步骤。
- **倾斜装饰** — 任何带 rotate(±2deg~±12deg) 的矩形、徽章或星形。没有它系统读起来太均匀。

## 该做与不该做

### 该做

- 主卡片用 4px 黑边框，次级 chrome 用 3px。边框阶梯是结构骨干。
- 每道 4px 边框配 8px 偏移阴影，每道 3px 边框配 4px 阴影。边框/阴影耦合不可谈判。
- 幻灯片背景在粉彩色板中轮换——米白、奶油、蓝、粉、绿、黄——保持视觉节奏。
- Inter 展示元素全用大写+负字距+800+ 字重。这组合 = 排版身份。
- 每个区域用标签药丸（3px 边框 + 4px 阴影 + 粉彩填充 + Space Grotesk 大写）作为通用区域眉毛。
- 给装饰矩形、统计卡、星形、徽章加倾斜（±2deg~±12deg）。
- 用黄色作为默认按钮色。
- 阴影做成纯黑零模糊，始终右下偏移。
- 每张幻灯片加至少一个装饰元素。
- 合页用纯黑地面 + 白字 + 12px 黄色偏移阴影。

### 不该做

- 不给卡片、按钮、标签药丸、图标方块、头像加圆角。禁止 border-radius（stat-deco-dot 除外）。
- 不模糊任何阴影。全是零模糊硬边。
- 不用彩色边框。边框永远是纯黑（合页框的 4px 白色边框是唯一例外）。
- Inter 展示字重不用句首大写。大写是强制要求。
- 不引入第六种粉彩。色板锁定在粉、蓝、绿、黄、奶油五色。
- 不给区域省略标签药丸。从背景直接跳到标题会打破编辑节奏。
- 正文不用模糊色或彩色。正文是纯黑或纯白/奶油。
- 不让所有卡片完美对齐。倾斜是手工感的本源。

## 响应式行为

为 1920×1080 设计（有效 100vw × 100vh）。字号用 clamp()，边框/阴影/结构内边距用固定 px。

- **≤1024px**：幻灯片内边距 60→40px，双列布局竖向堆叠，特性卡行堆叠，时间线堆叠（隐藏步骤连接器），统计网格和团队网格缩为 2 列。
- **≤640px**：统计和团队网格缩为 1 列，Hero 框和引文框内边距缩至 32px。

键盘导航：ArrowRight/Space 前进，ArrowLeft 后退。触屏水平滑动 50px 阈值触发。

## CJK 中文化

中文化时用 思源黑体 Noto Sans SC 替代 Inter/Space Grotesk 的双字体体系：
- **展示/标题**：Noto Sans SC 900（句首大写，0 字距）
- **正文**：Noto Sans SC 400
- **标签/chrome**：Noto Sans SC 600（无大写，0 字距）

关键调整：
- 行高增加 15-25%（正文 1.75-1.85，展示 1.15-1.25）
- 字距归零（Latin 版的负字距会压碎汉字）
- 去除 text-transform: uppercase（CJK 无大小写）
- 使用全角中文标点
- 中英文之间加空格（盘古之白）

系统的身份 80% 是结构、20% 是排版——4px 黑色边框、8px 硬阴影、五色粉彩、倾斜装饰、标签药丸才是粗野主义的载体，不管字体是大写还是句首。
