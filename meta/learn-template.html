画幅比例 16:10

比 16:9 多 6% 纵高，中文排版不局促；比 4:3 更接近现代屏幕。MacBook 原生比例，mockup 事实标准（1440×900、1920×1200）。

骨架屏占位

图片加载前用纯 CSS 骨架屏占位，避免布局偏移（CLS）。@keyframes 驱动 opacity 脉冲，零 JS 依赖。骨架条宽度递减模拟真实行长分布。

CSS only · 1.5s pulse

transform scale 缩放

hover 缩放用 transform: scale()，不走 width/height。transform 在 GPU 合成层执行，不触发 reflow，60fps 平滑。配合 overflow: hidden 裁切边缘。

GPU 合成 · 不重排

设计原则

版式画廊的 7+5+0 原则体系——7 条通用设计原则、5 条 AI 输出约束、0 容忍硬伤。

视觉及格线

用可量化的视觉标准定义"合格"。排版四要素（字号、行高、字距、行长）必须落在可读区间内，颜色对比度 ≥ AA 级。

量化指标 → 工具自动检测 → 不通过不发版

技术及格线

CSS 必须通过三关：无硬编码值、无 Google Fonts、无未压缩图片。Token 化率 100%，所有视觉属性从 :root 变量派生。

CI 门禁 → 静态扫描 → 阻断不合规提交

Token 优先

设计决策表达为 CSS 自定义属性，不是硬编码值。颜色、间距、阴影、圆角全部从 :root 变量注入，保证换肤只需换 token。

约束 → 模板必须声明 CSS 变量 → registry 校验

渐进增强

基础体验用纯 CSS + 语义 HTML，增强体验用少量 JS。骨架屏、动画、交互均检测 prefers-reduced-motion。

无 JS 仍可用 → 有 JS 更流畅
