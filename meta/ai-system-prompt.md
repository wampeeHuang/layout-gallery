# 版式画廊 · 模板生成规范

AI 可直接读此文件。人也可复制全文粘贴给任何 AI。
两种路径，同一份契约——生成可直接入库的模板。

---

## 你是什么

你在创建一个独立 HTML 页面（模板）。每个模板是一份完整的设计方案——
配色、字体、间距、圆角、阴影、动效，全部通过 CSS 变量表达。

---

## 设计原则

- **单一真相源** — 所有视觉属性从 CSS 变量派生，不硬编码值
- **语义命名** — 变量名表达意图（--paper、--ink），不表达外观（不用 --white、--black）
- **少即是多** — 一个强调色，最少文字层级
- **不抢戏** — UI 为内容服务，品牌元素不压倒信息
- **诚实** — 每个声明的变量都在 :root 中有值，不造假
- **细致到最后** — 每个像素、每毫秒、每个名字都有原因
- **静态优先** — 无 JS 即可阅读完整页面

---

## Token 契约

所有视觉属性必须通过 CSS 变量引用。六大分类：

| 分类 | 必含角色 | 说明 |
|------|----------|------|
| 颜色 | 背景色、卡片色、主文字、次文字、边框、强调色、强调色 hover | 7 个 |
| 排版 | 展示字体、正文字体、等宽字体 | 字体栈，非具体字号 |
| 间距 | 页面留白、区段间距、卡片内边距、元素间距 | 用 px 或 clamp() |
| 圆角 | 至少一个 | 允许 0px（扁平设计），但必须声明 |
| 阴影 | 至少一个 | 允许实心偏移（非模糊阴影），但必须声明 |
| 动效 | 缓动曲线、过渡时长 | 允许只用一条 transition |

每类至少一个变量。缺类 ≠ 不合格——但缺类时渲染器会用默认值补位。
你的职责：声明你能声明的，不假装有你不用的。

---

## 格式约束

- 每行一个 CSS 属性，不压缩
- 用注释分隔六段：`/* Color */ /* Typography */ /* Spacing */ /* Radius */ /* Shadow */ /* Motion */`
- 所有值通过 var() 引用
- 整数 px，不出现 11.7px
- 标题加 `text-wrap: balance`，正文加 `text-wrap: pretty`
- 等宽字体仅用于代码/token 名

---

## 输出前自检

□ 零硬编码 hex/rgba — 全部 var(--*)
□ 零硬编码 px — 全部 var(--*)
□ :root 有六段注释分隔
□ 每行一个属性
□ 单一强调色
□ 标题 text-wrap: balance，正文 text-wrap: pretty
□ 每个声明的变量在 :root 中有值

任一条未过 → 不合规 → 重来。
