Georgia 衬线大字报 × 边框网格 × 墨色反转 hover — 宣言感深底红影。反装饰、重结构。

设计概览

复古纸媒 × 粗野主义。Georgia 衬线做巨大标题，Inter 无衬线正文，一冷一暖对比。边框即装饰。

适用场景

公共声明、倡议页面、运动网站、编辑精选、个人宣言、独立出版物

不适合

企业内部文档、数据报告、电商落地页、需要大量数据表格的场景

设计基因

Georgia 衬线标题 / Inter 无衬线正文 / 锈红 accent / 纸白底盘 / 1px 边框区分层次

设计决策记录

为什么选这个值，不选那个值——每个 token 的决策逻辑。AI 生成新模板时以此为判断依据。

为什么标题用 Georgia，不用 Playfair Display？
Georgia 是系统预装字体，零加载成本。Playfair Display 需要 Google Fonts（中国被墙）。Georgia 的 x-height 更高，中文混排时基线对齐更好。
typography
为什么 accent 用锈红 #b84f35？
纸白底（L=96%）上需要暖色低明度（L≈40%）形成 WCAG AA 级对比度。锈红比正红（#f00）更克制，比橙色更沉稳，符合"纸媒宣言"的复古质感。
color
为什么默认无阴影，hover 才有？
粗野主义不依赖立体感。正常态用 1px border 区分层次足够。hover 态加阴影是微妙的反馈信号，不是默认视觉语言。
shadow
为什么间距基准是 4px 而不是 8px？
4px 可以整除任意值，8px 在微小间距（如 12px）时无法整除。但实际上这个模板的间距是 96/64/48/32/16/8——确实是 8px 倍数。这里保留 4px 声明是为了允许未来出现 4px/12px/20px 等非 8px 倍数的间距。
spacing
为什么圆角最大只到 4px？
圆角越大越"软"越"友好"，粗野主义要求硬朗。4px 是既保留可交互暗示、又不失硬朗的最大值。超过 4px 就会偏离粗野主义的视觉锚点。
radius

## Design Kit: Paper Manifesto (纸媒宣言)

### Philosophy
Editorial brutalism. Georgia serif headlines + Inter sans-serif body.
Oxide red accent (<5% surface). 1px borders instead of shadows.
Paper-white ground. Tight tracking. Center hero, left-align content.

### Colors
- --paper #f4efe7 → page bg
- --ink #1b1916 → text / dark blocks
- --oxide #b84f35 → accent (sparingly)
- --sun #d89a57 → hover / quote borders

### Type
- Display: Georgia 400, clamp(48px,6vw,72px), tracking -0.03em
- Body: Inter 350, 17px/1.75
- Mono: SF Mono 500, 11px — labels only

### Layout
- Max-width 1080px, page-padding 48px
- Spacing: 96/64/48/32/16/8 (4px base, 2:1 ratio)
- Grid gaps: 1px borders between cards

### Do's
- Large serif headlines, tight tracking
- Accent under 5% of page surface
- 1px borders for depth, not shadows
- Center hero, left-align body

### Don'ts
- Never bold (600+) body text
- Never box-shadow default state
- Never radius above 4px
- Never accent as background fill
