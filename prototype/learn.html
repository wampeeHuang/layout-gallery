推荐书籍

设计思维 + 实践落地——从原则到代码。

设计思维

The Design of Everyday Things

Don Norman

设计心理学圣经。可发现性、反馈、映射、约束、示能——五条原则覆盖所有交互设计。

#交互设计 #认知心理学

Refactoring UI

Adam Wathan & Steve Schoger

从零到一的设计实战书。层级、配色、字体、间距、动效——每章都有 before/after 对比。

#UI设计 #实用

Thinking with Type

Ellen Lupton

排版设计入门经典。字母/文本/网格三部分，从字体选择到页面布局全覆盖。

#排版 #字体

Grid Systems in Graphic Design

Josef Müller-Brockmann

网格系统圣经。虽然写于印刷时代，但对网页布局仍有根本性指导意义。

#网格 #布局
Web 开发

Every Layout

Heydon Pickering & Andy Bell

CSS 布局新思维——不写媒体查询，用弹性盒和网格做内在响应式。彻底改变你对布局的认知。

#CSS #布局 #响应式

Web Accessibility Cookbook

Manuel Matuzovic

现代无障碍实践指南——从语义 HTML 到 ARIA，从键盘导航到屏幕阅读器测试。

#无障碍 #实用
设计系统

Design Systems

设计系统从概念到落地。Token 分层、组件 API、共享语言、治理流程。

#设计系统 #流程

Atomic Design

Brad Frost

原子设计方法论——Atom → Molecule → Organism → Template → Page。在线免费阅读。

#方法论 #组件化
