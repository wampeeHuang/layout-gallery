# 如何选模板 · How to Pick a Template

## 决策三问

选模板前先回答三个问题：

1. **什么场景？** — 演讲 / 汇报 / 发布 / 教学 / 个人分享？
2. **多少人？** — 大屏（>50 人）/ 小屏（<10 人）/ 线上？
3. **什么调性？** — 理性专业 / 温暖人文 / 冲击视觉 / 极简克制？

## 按场景推荐

| 场景 | 推荐模板 | 原因 |
|------|---------|------|
| AI/科技产品发布 | template-swiss | Swiss style — 克莱因蓝，理性 |
| 企业战略汇报 | blue-professional | 专业蓝，正式，数据友好 |
| 设计/创意展示 | studio | 黑底黄字，海报感 |
| 学术/研究报告 | soft-editorial | 象牙底，优雅克制 |
| 数据密集型 | long-table | 专为长表格设计 |
| 品牌/生活方式 | biennale-yellow | 太阳能黄，温暖高级 |
| 建筑/空间 | brutalist-paper | 粗野主义，混凝土感 |
| 文学/阅读分享 | template | 墨水经典，电子杂志 |
| 年轻/Z世代 | broadside | 粗体大字报，复古 |
| 生态/可持续 | editorial-forest | 森林绿，自然感 |
| 时尚/艺术 | pink-script | 黑底亮粉，前卫 |
| 工业/汽车 | template-swiss (安全橙) | 瑞士风橙色 accent |

## 按密度推荐

| 密度 | 模板 |
|------|------|
| 高密度（每页信息多） | template-swiss, blue-professional, long-table |
| 中密度（图文平衡） | soft-editorial, template, broadside |
| 低密度（视觉优先） | studio, brutalist-paper, bold-poster |

## 按风格推荐

| 设计风格 | 模板数 | 代表作 |
|---------|--------|--------|
| swiss | 1 | template-swiss |
| editorial | 12 | soft-editorial, biennale-yellow, editorial-forest 等 |
| brutalist | 2 | brutalist-paper, bold-poster |
| creative | 7 | studio, block-frame, creative-mode 等 |
| retro | 4 | retro-windows, retro-zine, pin-and-paper, stencil-tablet |
| industrial | 2 | signal, vellum |

## 快速选表

如果用户说 | 就推荐
-----------|------
"不知道选啥" | template-swiss (最安全)
"AI/技术" | template-swiss (IKB 蓝)
"人文/温暖" | template (墨水经典)
"艺术/设计" | studio
"数据/表格" | long-table
"年轻/Vibe" | broadside 或 capsule

## 怎么展示给用户

1. 列 2-3 个候选，每个一句话描述 + 一个理由
2. 不要让用户看 28 个全部——决策瘫痪
3. 用户选了之后，直接开始生成，不要再确认
